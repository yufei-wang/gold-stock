# 券商月度金股总结

自动化数据看板：券商月度金股推荐次数、跟上月对比及至今涨幅可视化。

**在线访问**：https://yufei-wang.github.io/gold-stock/

## 功能

- 每月券商推荐次数汇总（按证券名称）
- 与上月推荐次数对比（新增/增加/持平/减少）
- 至今涨幅列（以当月首个交易日收盘价为基准，日频更新）
- 按推荐次数 / 较上月 / 至今涨幅点击排序
- 月份切换、搜索、筛选
- 行业分布饼图 + TOP15 推荐柱状图

## 数据更新

每日下午 16:30（A股收盘后）自动拉取股价并重建站点。

## 技术栈

- 静态 HTML + ECharts 图表
- Python (openpyxl) 解析 Excel → 生成 data.js
- iFind 接口获取日频股价
- GitHub Pages 托管
